# 9. Engineering Gap Analysis — Current Code vs. Required

Comparing `src/lib/templates/darbartech-certificate-v1.ts` and `src/lib/renderer/certificateRenderer.ts` against the specification in this document set:

| Area | Current state | Required for PSD-accurate output |
| --- | --- | --- |
| Fonts | Renderer only embeds pdf-lib's 14 Standard fonts (Helvetica, Times, Courier families) via `StandardFonts`. | Embed Montserrat (5 weights) and Cormorant Garamond Bold as custom TrueType fonts. pdf-lib requires the `@pdf-lib/fontkit` plugin registered via `PDFDocument.registerFontkit()` before `embedTtf()` to embed non-standard fonts. |
| Colour palette | `colors` block uses generic `brandNavy #0a2463`, `brandGold #c9a227`, `brandCyan #3e92cc` — none of these match the PSD. | Replace with the 5 verified colours in Section 3: `#061A50` (navy), `#1669B2` (blue), `#34C5CA` (teal), `#060808` (ink), `#FFFFFF`. There is no gold anywhere in the master design — the grade badge is teal-filled with white text. |
| Field coordinates | All 20 `TemplateField` entries use placeholder x/y/width/height values unrelated to the PSD (e.g. `recipientName` at x:30 y:82 w:237, centered, 32pt). | Replace every field's x/y/width/height/font/fontSize/color/alignment with the values in Section 5 (e.g. `recipientName` should sit at x:87.5mm y:64.0mm, Cormorant Garamond Bold 191.7pt, left-set within a 121mm box, colour #061A50). |
| Decorative shapes | `TemplateConfig` / `TemplateField` have no shape/line/rectangle concept at all — `certificateRenderer.ts` only draws one plain rectangular border (`drawPageBorder`). | Add a `shapes: ShapeConfig[]` array to `TemplateConfig` (rect / triangle / line primitives with x, y, w, h, fill, stroke, strokeWidth, rotation) and a `drawShapes()` renderer step, so the corner ribbons, all divider lines, the diamond bullet, the grade badge, and the footer bar can be reproduced. |
| Module grid | `moduleConstraints` assumes a variable-count (3–6) single block of stacked text, laid out generically by the renderer. | The PSD grid is a fixed 4-column layout (numeral + title + subtitle per column) with 3 vertical divider lines. Either hard-code 4 columns for this template version, or extend the module-layout logic to branch on column count so 4-column mode reproduces the exact positions in Zone 6. |
| Grade badge | `grade` is a plain centered text field with no container graphic. | Add the teal rounded-rectangle badge (Rectangle 7) as a shape behind the two-run "Final Grade \| " + grade-value text, matching the two font-size runs (41.7pt label / 75–100pt value) in Zone 7. |
| Multi-colour text runs | `renderTextInField()` renders a field as a single colour/font/size — no per-run styling. | Add run-level support (array of `{text, font, size, color}` segments per field) for: the hero headline ("Certificate of" / "completion"), the duration sentence (4 runs), and the grade badge (2 runs) — see Section 5, Zones 4, 5 and 7. |
| Page border / corners | `drawPageBorder()` draws a single flat rectangle inset from the edge. | Replace with the exact Rectangle 1 frame plus the TOP LEFT and RIGHT BOTTOM shape groups from Section 6, including the negative-coordinate bleed geometry. |
